# Assets

## Terminal README template (colored SVGs)

GitHub strips most inline CSS, so colors live in these SVGs:

| File | Role |
|------|------|
| `terminal-whoami.svg` | Hero terminal window |
| `likes.svg` | Bio / interests panel |
| `prompt-*.svg` | Green `$` section headers |

Edit the SVG text to tweak copy or palette (`#3dd68c` green, `#07100d` bg).
The dynamic music card is written to `now-playing.svg` by `scripts/update-readme.mjs`.

## `asta.gif`

Place a **user-owned or properly licensed** Asta (Black Clover) pixel-art animation here:

```text
assets/asta.gif
```

Until the file exists, GitHub may show a broken image — that is intentional.

Do **not** commit random copyrighted anime artwork scraped from the web.
